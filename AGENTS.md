# Инструкции для ИИ-агентов (AI Agent Guidelines)

Перед выполнением любых задач по модификации кода, добавлению эндпоинтов, миграциям или изменению конфигурации проекта **ОБЯЗАТЕЛЬНО ознакомься с регламентом** в файле [ARCHITECTURE.md](./ARCHITECTURE.md).

---

## Ключевые правила проекта:

1. **Единый источник правды для версии**:
   * Версия хранится **только** в `pyproject.toml` (`[project] version = "..."`).
   * Запрещено хардкодить версию строками в коде или переменных окружения.
   * Версия в рантайме берется из `importlib.metadata.version("taskmanager")`.

2. **Слои архитектуры**:
   * Маршрутизаторы (`src/taskmanager/api/routes/`) остаются тонкими. Бизнес-логику и работу с БД пиши только в сервисах (`src/taskmanager/services/`).
   * Статусы и категории бери из перечислений (`src/taskmanager/models/enums.py`), никаких магических чисел.
   * Ошибки отсутствия сущностей оформляй через доменные исключения (`src/taskmanager/core/exceptions.py`).

3. **Язык**:
   * Все комментарии в коде и docstring-и пиши строго на **русском языке**.

4. **Проверка перед завершением задачи**:
   * Обязательно запускай тесты: `uv run pytest -v` (все тесты должны быть зелеными).
   * Обязательно проверяй форматирование и линтер: `uv run ruff check .` и `uv run ruff format .`.
